# Online Feedback System (Responsive)

Tech: HTML5, CSS3 (Grid + Flexbox + media queries), JavaScript (ES6+), localStorage.

## Run
1. Unzip the folder.
2. Open the folder in VS Code.
3. Right click `index.html` -> "Open with Live Server"
   (or just double-click `index.html` to open in the browser).

## Features
- Feedback form with live validation (name, email, topic, star rating, message)
- Character counter (300 max)
- Data saved in browser localStorage (no backend needed)
- Average rating + total responses
- Filter by topic, delete one / delete all
- Fully responsive: desktop, tablet, mobile
